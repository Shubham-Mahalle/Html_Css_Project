# ShopEasy - E-Commerce Practice Project

ShopEasy is a simple beginner-level e-commerce webpage created to practice **HTML5 and CSS3 fundamentals**.

The project contains a navigation bar, product categories, product cards, filters, product information table, order form, contact section, and footer.

## Project Overview

ShopEasy is designed as a small shopping interface where users can:

- Browse product categories
- View available products
- Filter products using different options
- View product information
- Add products to cart
- Fill out an order form
- Select a payment method
- View contact information

This project mainly focuses on practicing **HTML5 semantic elements, CSS fundamentals, Flexbox, and CSS Grid**.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- HTML Forms
- Tables
- Semantic HTML
- Basic CSS Hover and Focus Effects

## Features

### 1. Navigation Bar

The navigation bar contains links to different sections of the page:

- Home
- Products
- About
- Contact
- Cart

The navigation bar uses **Flexbox** for alignment and is fixed at the top of the page.

### 2. Home Section

The home section contains:

- ShopEasy heading
- Short description
- Shop Now button
- Shopping image

The `Shop Now` button takes the user directly to the Products section.

### 3. Product Categories

The project contains five product categories:

- Electronics
- Clothing
- Shoes
- Books
- Accessories

CSS Grid is used to arrange the categories.

### 4. Product Filter

The sidebar provides different filtering options:

- Categories
- Price
- Availability
- Rating
- Brand

The filter section demonstrates the use of:

- Checkboxes
- Radio buttons
- Fieldset
- Legend
- Labels
- Submit button
- Reset button

### 6. Product Information Table

A table is included to display basic product information.

It demonstrates the use of:

- `<table>`
- `<thead>`
- `<tbody>`
- `<tr>`
- `<th>`
- `<td>`

### 7. Order Form

The project includes a complete basic order form.

Users can enter:

- Full Name
- Email
- Phone Number
- City
- Product
- Quantity
- Address
- Size
- Payment Method
- Delivery Instructions

The payment options are:

- Cash on Delivery
- Credit/Debit Card
- UPI

The form also includes HTML5 validation using attributes such as:

- `required`
- `type="email"`
- `type="number"`
- `min`

### 8. Contact Section

The Contact section contains:

- Address
- Email
- Phone number
- Instagram link

The email and phone number use `mailto:` and `tel:` links.

### 9. Footer

The footer contains:

- ShopEasy name
